地址校验规则（保存时） · trim 前后空白

· 空串 / 非法 → 红框 + 错误行，不保存

⑦ URL 重写效果（实现说明）

启用后读类命令注入 -c url.<前缀>.insteadOf=https://github.com/，不改用户全局 git 配置。

// 禁用（现状）
https://github.com/GaoHu1997/dsh-git-branch.git
▼ 启用后重写为
https://gh-proxy.com/https://github.com/GaoHu1997/dsh-git-branch.git
作用范围 · fetch / 更新 / 建 worktree 前的 fetch → 走加速 ✓
· push → 保持直连（公共镜像不支持 receive-pack）
· SSH remote（git@github.com:）→ 不重写
  • 加速站不可用时 fetch 报错 toast 尾部追加「若加速地址不可用，可停用国内加速或更换地址」。
