# 0012 — 发布 v1.0.2 补丁版本

状态: 已接受

## 背景

设置面板配置读取修复（0011）合入后，已发布的 1.0.1 不包含该修复，用户拿不到修正，需要发布补丁版本。用户明确指示升号并推送 tag 与 release。按 AGENTS.md 约定，升号作为独立 chore 提交。

## 决策

将 `package.json` 的 `version` 从 `1.0.1` 升到 `1.0.2`，作为独立 chore 提交，打附注 tag `v1.0.2` 推送，由 release 工作流（0010）发布 npm 并创建 GitHub Release。备选方案：归入次要版本 1.1.0——被否决，本次只有缺陷修正，无新功能，按语义化版本使用补丁号。

## 影响

- 正面：npm 与 GitHub releases 的最新版本包含设置面板修复，用户可升级。
- 负面：多占用一个版本号；发布前若再发现缺陷需再升 1.0.3。
